    Permissions

    Restricted — supplied inputs and outputs only. The default for new apps.

    Custom AI programs — explicit per-connection grants, with your OS account’s file and network permissions. Their declared capabilities do not provide a native sandbox.

    Commands — individually granted per app, using your account’s file and network permissions.

    Folders — select access in each connection’s Folder access. Changes ask first unless you enable automation.

    Privacy & local data

    Sign-in stays in the installed clients. Personal provider privacy settings apply. No paid API fallback or remote relay.

    Closing a requesting app tab cancels its jobs within 12 seconds. Network loss or tab suspension can do the same. This panel can close independently.

    Sharing switches omit structured metadata; program output can still identify its source. Diagnostics are off by default, bounded and redacted when shared.

    Finished records discard their inputs. History is kept by default; each connection can override the global setting in Access. With history off, finished requests disappear immediately; results and files stay in memory only until sent to the app, for at most one minute. Open sessions keep their context until ended. Clearing or disabling history removes saved output and WDC files, keeping minimal replay receipts. Native clients and requesting apps may keep their own copies.
