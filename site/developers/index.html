Add WebDeviceCable to your website.

Your users run AI requests on the Codex or Claude Code they already have, or on other programs they choose to allow. You need no provider API keys, and you pay nothing for their AI use.

Two ways to connect

Pick where your AI requests start. Most sites start with the web page.

Option 1 · No server needed

From your web page

Your page’s JavaScript talks straight to WebDeviceCable on the user’s computer.

Your web page request answer User’s computer
  • Nothing to host. Add one npm package to your front end.
  • Requests run while the user has your page open.
npm install @webdevicecable/sdk

Web page guideSee the example

Option 2 · You run a small server

From your server

Your backend sends requests through a relay: a small server you host that passes encrypted messages between your backend and WebDeviceCable.

Your server request answer Your relay asks for work request answer User’s computer

The user’s computer reaches out to your relay to ask for work and to send back answers. The relay never connects to the user’s computer, so nothing there is opened to the internet.

  • Requests can run while your website is closed, for example from background jobs.
  • You run the relay yourself, with Docker.
npm install @webdevicecable/relay

Server and relay guideSee the example

You can use both at once. Either way, each user approves your site in WebDeviceCable, chooses which program it may use, and can review every request. All requests are signed and encrypted.
