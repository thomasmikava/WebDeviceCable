Let websites use the AI tools on your computer.

WebDeviceCable is a small free app. Websites you approve can use the AI plan you already have, so you need no new account and no API key. Your sign-in stays on your computer.

How it works

  1. 1

    Install WebDeviceCable. Sign in to Codex or Claude Code as you normally do.

  2. 2

    On a website that supports it, click Connect to WebDeviceCable.

  3. 3

    Approve the website in WebDeviceCable. Its AI requests now run on your computer.

Works with the programs you already use

WebDeviceCable is made for AI tools first. It can run other programs on your computer too, but only the ones you add.

  • Codex

    Built in. Uses your existing sign-in. Can also create and edit images.

  • Claude Code

    Built in. Uses your existing sign-in.

  • Your own programs

    Another AI tool, or any other program on your computer. You add it yourself in WebDeviceCable’s settings file, and a website can run it only if you allow it.

You approve every website.

Nothing connects until you click Connect. You choose which program each website may use.

Your sign-in stays on your computer.

WebDeviceCable uses the Codex or Claude Code you already have. It never reads or copies your login.

See every request.

You can ask to approve each request before it runs, and look back at what ran.

Install

This is an early release. The installers are not signed by a publisher yet, so your computer will ask you to confirm.

Mac

  1. Open the downloaded .pkg file and follow the installer.
  2. If macOS says the developer cannot be verified, open System Settings → Privacy & Security and click Open Anyway. Apple’s help
  3. Open WebDeviceCable from Applications.

Windows

  1. Open the downloaded Setup.exe file. It installs for you only, without administrator access.
  2. If Windows shows “Windows protected your PC”, click More info, then Run anyway. Microsoft’s help
  3. Open WebDeviceCable from the Start menu.

Linux

  1. Extract the downloaded .tar.gz file.
  2. Open a terminal in that folder and run ./install.sh. No root access is needed.
  3. Open WebDeviceCable from your applications menu.

WebDeviceCable sits in your menu bar or system tray. Click it to open its control panel in your browser. If a website sent you here, go back to it and click Connect to WebDeviceCable.

Updates are manual for now: download the new version and install it over the old one. To hear about new versions, open the GitHub page and choose Watch → Custom → Releases. You need a free GitHub account for this.

Questions

Is it free?

Yes. WebDeviceCable is free and open source. It uses the Codex or Claude Code you already have, so your plan’s usual limits apply. It never switches to a paid API.

What do I need?

A Mac, Windows or Linux computer with Codex or Claude Code installed and signed in. WebDeviceCable finds them on its own. You can also add other programs yourself.

Don’t have either yet? Install Codex or Claude Code first.

What can a connected website do?

Send AI requests to the program you chose for it, and read the answers. It cannot see your folders or run commands unless you allow that in WebDeviceCable.

WebDeviceCable has not had an independent security review yet.

Which websites work with it?

Websites that have added WebDeviceCable show a Connect to WebDeviceCable button.
